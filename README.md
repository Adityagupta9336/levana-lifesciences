# Levana Life Sciences

Your trusted licensed medical store in Meerut, Uttar Pradesh. Providing genuine medicines, pharmacist-verified orders, and friendly service, both online and in-store.

## 🚀 Features
- **Online Prescription Upload**: Fast and secure prescription verification.
- **Same-Day Delivery**: Rapid delivery across Meerut.
- **Licensed & Verified**: Fully compliant with drug laws and GST registered.

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- Web3Forms for contact handling

## 📦 Deployment
The project is configured to be served from the `medical-store/` directory.
